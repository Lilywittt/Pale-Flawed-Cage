- **2023.03 – 2025.07（第一季 1.0 完结版）**：完成开篇初稿《梦醒》与第一季 1.0 全 14 章（`Chapter 01–14`）。
- **2023.11 – 2025.05（旧版续篇《何以渡忘川》）**：完成出题篇与解题篇共 11 章及分卷大纲；后为拔高整体世界观格局主动调整主线路线，并在 2026《蜉蝣》中将其收编为轮回初线。

- **2026.01 – 2026.03（第二季 2.0 精修版）**：大幅重写《穹窿》前半卷 `Episode 01–07`，衔接后半卷全卷。
- **2026.04 – 2026.09（第一季 3.0 全面重制与总纲闭环）**：扩写新版《全书总大纲》、核心角色设定与《蜉蝣》等番外，完成第一季 3.0 重制版 `Episode 01–07`。
